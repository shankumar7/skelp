The IPL-style player auction you play with your friends, fully offline.

**Download `skelp.apk` below**, open it on your Android phone (7.0 or newer) and allow *Install unknown apps*.

### Fixed in 1.2.1
- **The app closed as soon as it opened** for anyone already signed in whose phone was not connected to Wi-Fi (on mobile data, or sharing the hotspot). Searching for arenas tripped a bug in the network library that crashed the app. That is fixed, and a background thread leak in the same code is gone too.
- If anything unexpected ever goes wrong, the app now shows a recovery screen with a *Try again* button instead of closing.

### From 1.2
- Join an arena by scanning the host's QR code
- Hotspot guide in the lobby, Wi-Fi status and settings shortcuts on the dashboard
- Connections are bound to Wi-Fi so phones on a hotspot reach each other

### Good to know
- No internet needed: one phone hosts, the rest join over the same Wi-Fi or hotspot
- The host phone must keep Skelp! open during an auction
- The APK is signed with a debug key, which is fine for sharing the file directly
